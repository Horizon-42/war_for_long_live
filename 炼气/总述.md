# 物理基础
在元脑结构被发现之前，思想是唯一的可以超远距离呼应、共鸣的东西。
但元脑结构，可以在宏观物质层面引发类似的共鸣。已经证实，这是一种量子相干，或者说，元脑结构能够屏蔽量子退相干。
而其相干的范围，取决于是否构造了回路，回路范围有多大。
所谓回路，就是局部相干的物质相互作用必须从元脑发起，最终又回到元脑。这与直接的量子纠缠不同，整个过程是符合狭义相对论的。
而元脑可以记住特定回路的相位特征，因此，相似/相同的回路的二次构建十分容易。

# 引气
所谓引气，本质上通过重塑大脑神经元连接，调频大脑，以与特定的物质构成宏观量子波函数的相干，并推动相干链路闭环，形成回路。一旦回路形成，元脑就可以对相位特征进行微调，以扩大回路范围，或者更改回路结构。
炼气士所引之气，指的其实是特定的相干回路。而引气的数量，理论上没有上限。所引之气的真正数量，往往也是修士最大的秘密。
